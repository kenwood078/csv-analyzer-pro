### Описание
**CSV Analyzer Pro** предназначен для быстрого исследования табличных данных, загруженных в формате CSV. Программа автоматически определяет кодировку и разделитель, обрабатывает даты и предоставляет набор инструментов для статистического анализа и построения интерактивных графиков.

Основные возможности:
- **Загрузка CSV** – автоматическое распознавание кодировки (библиотека `chardet`) и разделителя (`csv.Sniffer` + эвристический fallback).
- **Просмотр и редактирование** – отображение данных в интерактивной таблице `st.data_editor` с возможностью изменения значений и скачивания результата.
- **Статистический анализ** – вычисление среднего, медианы, стандартного отклонения, минимума, максимума и количества непустых значений для выбранного числового столбца.
- **Визуализация** – построение графиков с помощью Plotly:
  - Гистограмма распределения с наложенным box‑plot.
  - Линейный график с опциональной агрегацией (сумма, среднее, медиана, количество) по оси X.
  - Диаграмма рассеяния с опциональной агрегацией и цветовой группировкой.
  - Столбчатая диаграмма с выбором агрегирующей функции (сумма, среднее, медиана, количество) и режима отображения (группировка, накопление, доли, наложение).
  - Тепловая карта корреляции и матрица рассеяния для исследования взаимосвязей между числовыми признаками.
- **Экспорт графиков** – скачивание любого графика в формате PNG(требуется `kaleido`).
- **Кэширование и состояние сеанса** – все ресурсоёмкие операции (загрузка, парсинг, построение графиков) кэшируются через `@st.cache_data`, обеспечивая высокую скорость повторных действий.

### Установка зависимостей
Для запуска программы необходим Python 3.10 или выше. Рекомендуется использовать виртуальное окружение.

1. Клонируйте репозиторий на свой компьютер.
2. Установите необходимые пакеты с помощью pip:

```bash
pip install streamlit pandas chardet plotly kaleido
```

### Запуск
Перейдите в папку с проектом и выполните команду

```bash
streamlit run app.py
```

После этого приложение откроется в браузере по адресу http://localhost:8501. Загрузите любой CSV-файл (расширения .csv или .txt) и начните анализ.
